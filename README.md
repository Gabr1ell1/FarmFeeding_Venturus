## 🎯 Objetivo da Plataforma

A FarmFeeding foi desenvolvida com o objetivo de organizar e facilitar a gestão rural por meio de:

- Cadastro de grupos de animais  
- Controle de produtos  
- Gerenciamento de perfil do usuário  
- Sistema de autenticação seguro
